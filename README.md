# 🎮 Gerenciador de Coleção de Jogos

Um sistema de linha de comando (CLI) desenvolvido em Python para organizar e rastrear o status de videogames pessoais. 

Este projeto foi criado como objeto de estudo prático para aprofundar conceitos fundamentais de programação e estruturação de dados.

## 🚀 Funcionalidades

O sistema permite que o usuário gerencie sua biblioteca através de um menu interativo com as seguintes opções:

* **Adicionar Novos Jogos:** Registro de títulos com definição de status.
* **Sistema de Status:** Classificação dos jogos em 4 categorias:
  * 🎯 *Quero jogar*
  * 🕹️ *Jogando*
  * 🏆 *Zerado* (com suporte a nota, tempo de jogo e avaliação pessoal)
  * 🛑 *Dropado* (com registro do motivo da desistência)
* **Exibição da Lista:** Leitura e formatação dos dados salvos para visualização rápida no terminal.

## 🧠 Aprendizados e Habilidades Aplicadas

O desenvolvimento deste código focou na aplicação prática dos seguintes conceitos em Python:

* **Estruturas de Controle:** Uso avançado de laços de repetição (`while True`) e quebras de fluxo (`break`, `continue`) para navegação entre menus.
* **Lógica Condicional:** Encadeamento de verificações com `if`, `elif` e `else` para guiar a interação do usuário.
* **Manipulação de Dados:** Armazenamento volátil utilizando **Listas** (`arrays`) e **Dicionários** para agrupar múltiplos atributos (nome, nota, horas) em um único escopo de jogo.

## 🛠️ Tecnologias Utilizadas

* **Python 3:** Linguagem principal do projeto.
